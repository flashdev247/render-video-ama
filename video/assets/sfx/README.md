# Hiệu ứng âm thanh

Tự tạo bằng code (`scripts/make-audio.py`, cùng lệnh với nhạc nền), không lo bản quyền.

| File | Khi nào |
|---|---|
| `whoosh.mp3` | Mỗi lần chuyển cảnh (`transitions()` trong `templates/base.mjs`) |
| `zap.mp3` | Linh vật (brand.mascot = "tia") xuất hiện đầu video |
| `pop.mp3` | Linh vật giơ ngón cái / ăn mừng |
| `ding.mp3` | Cuối video, linh vật ăn mừng; cảnh "Sau" của trước / sau, "Sự thật", đáp án đố vui |
| `hit.mp3` | Con dấu "HIỂU LẦM", cảnh "Trước đây" |
| `click.mp3` | Con trỏ bấm (mẫu quay màn hình web) |
| `type.mp3` | Gõ code (mẫu dựng web 30 giây) |
| `tick.mp3` | Đếm ngược (mẫu đố vui A/B) |
| `ting.mp3` | Tin nhắn đến (mẫu khung chat) |
